# Jack Network

Marketing site for Jack Network — a Minecraft server running practice PvP and survival.

## Stack

- Next.js 16 (App Router, Turbopack)
- React 19
- Tailwind CSS 4
- TypeScript

## Development

```bash
npm install
npm run dev
```

## Quality bar

`rules.txt` in this repository is the binding design and development brief. Every change must satisfy it, including the mandatory visual QA loop (`BUILD → RUN → INSPECT → SCREENSHOT → FIND PROBLEMS → FIX → REPEAT`) and mobile QA at 320–1440px+ before anything is called finished.
